# v1.0.5 发布说明

`1.0.5` 是 `1.0.4` 之后的兼容增强版本。本次发布重点补齐数据库形态的服务层幂等、幂等观测、模块选择文档、依赖边界治理和发布站点校验。

## 新增能力

- 新增 `under-utils-jdbc`，提供基于 Spring JDBC 的 `JdbcIdempotencyStore`，用于不引入 Redis 但已有业务数据库的服务。
- 新增 `under-utils-jdbc-starter`，在 `under.utils.idempotent.store=jdbc` 且存在 `JdbcOperations` 时自动装配 JDBC 幂等 store。
- `under-utils-jdbc` 提供 MySQL/PostgreSQL 建表脚本，starter 默认创建可关闭、可调间隔的过期记录清理任务。
- `under-utils-spring` 新增 `IdempotencyObserver` 事件模型和 `MicrometerIdempotencyObserver`，可将 begin、business、complete、release 等幂等事件写入 Micrometer counter、timer 和 observation。
- `under-utils-spring-starter` 新增 `under.utils.idempotent.observation.enabled`，在存在 `MeterRegistry` 且没有用户自定义 observer 时自动接入幂等观测。
- 新增 `docs/MODULE_SELECTION.md`，收敛模块选择矩阵、starter 入口策略和后续轻量化治理目标。

## 行为调整

- `IdempotentAspect` 在业务异常后释放幂等 key 失败时保留原业务异常，并把释放失败追加为 suppressed exception，避免 store 故障遮蔽真实业务失败。
- 父 POM 显式声明 Lombok 和 Spring Boot configuration processor 的 annotation processor path，starter POM 不再把 configuration processor 作为普通 optional 依赖。
- 测试构建显式预加载 Byte Buddy agent，并收敛预期异常、MockWebServer、MyBatis 集成测试、Redisson 关闭阶段和性能样例输出，减少 CI 日志噪音。
- 站点依赖分组调整为生产依赖只保留浏览器运行时需要的 `gsap`，Astro 和 Markdown 渲染工具进入 devDependencies。

## 兼容性

- 源码兼容：面向 `1.0.4` 的已发布 public API 保持兼容。
- 新 artifact：`under-utils-jdbc`、`under-utils-jdbc-starter`。
- 新 public API：`JdbcIdempotencyStore`、`JdbcIdempotencyOptions`、`JdbcIdempotencyCleanupScheduler`、`IdempotencyObserver`、`IdempotencyEvent`、`IdempotencyOperation`、`IdempotencyOutcome`、`MicrometerIdempotencyObserver` 等。
- 新配置 key：`under.utils.idempotent.jdbc.*`、`under.utils.idempotent.observation.enabled`。
- `under-utils-jdbc-starter` 不进入旧聚合 `under-utils-starter`；只有显式引入 starter 并设置 `store=jdbc` 时才启用。
- 新 JDBC 模块在首次发布前没有旧基线，API 兼容检查继续以 `1.0.4` 覆盖既有稳定运行时模块；JDBC 模块通过单元测试、starter 自动装配测试和文档边界确认。
- Maven Central 发布目标版本：`1.0.5`。

## 可追溯性

- Review 来源：enterprise deployment review / module weight review / release readiness review。
- 回归测试：
  - JDBC 幂等 store 的 begin、complete、release、TTL、owner token、表名白名单和 payload 参数绑定。
  - JDBC starter 在 `store=jdbc`、缺少 `JdbcOperations`、用户自定义 `IdempotencyStore`、关闭清理任务等条件下的自动装配行为。
  - Micrometer 幂等 observer 的 counter、duration 和 observation 接入，且不记录业务 key。
  - `IdempotentAspect` 在业务异常和释放失败同时发生时保留原异常并追加 suppressed exception。
